# Glossary

The words Tikido uses for its own ideas. Use one translation per term everywhere: in a button, a hint and
a notification alike. When you add a language, add a column.

## Names: never translate

| Term | Note |
| --- | --- |
| **Tikido** | The app. |
| **Tiki** | The hedgehog who hosts the app and speaks in its messages. |
| **Pro** | The paid plan (coming later). |
| **DM Sans** | A font name in the theme editor. |

The other friends (`mascots.*.name`: Unicorn, Owl, Fox, Penguin, Panda) are plain animal words: translate
them the way a child would call the animal.
